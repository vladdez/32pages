# Изображения в начале глав

Изображение появляется сразу под датой, перед текстом главы. Сейчас в книге 20 глав с датами. Пока оригинал не добавлен, показано нейтральное место для изображения.

## Как добавить фотографию

1. Скопируйте выбранную фотографию в эту папку. Исходный семейный снимок оставьте отдельно.
2. Назовите копию как в таблице ниже. Если файл имеет формат PNG или WebP, не переименовывайте расширение в JPG: поменяйте имя в `content/chapter-images.json`.
3. В `content/chapter-images.json` для нужной даты заполните `alt` — краткое описание снимка. Поле `caption` — необязательная подпись под ним. Кавычки внутри текста записывайте как «ёлочки».
4. Обновите книгу командой из главной инструкции README.md или попросите меня подключить фотографии.
