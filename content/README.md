# Материалы книги

Авторский источник расположен в корне проекта:

- `../32 страницы о моем отце.pdf` — исходный PDF.
- `../32 страницы о моем отце.md` — утверждённый текст из 32 страниц.

Текст подключён к сайту: `../book/index.html` создаётся из Markdown командой `python3 scripts/build_book.py`, запущенной из корня проекта. Оглавление формируется автоматически. Подробная инструкция находится в главном README.md.

`chapter-images.json` связывает дату каждой главы с фотографией в `assets/images/chapters/`, её описанием (`alt`) и подписью (`caption`). Пока файл фотографии не добавлен, показана заглушка.
